# Tarot Rider-Waite — Trải Bài Ngẫu Nhiên

Trang bói bài Tarot chuyên nghiệp, chạy hoàn toàn phía trình duyệt, không cần
máy chủ. Người dùng nhập câu hỏi (không bắt buộc), chọn kiểu trải bài, xáo
bài, bấm lật từng lá và xem giải nghĩa bằng tiếng Việt.

## Tính năng

- Bộ bài đủ 78 lá Rider-Waite-Smith (22 lá Ẩn Chính + 56 lá Ẩn Phụ),
  ảnh gốc Pamela Colman Smith (1909, phạm vi công cộng) từ Wikimedia Commons.
- 3 kiểu trải bài: 1 lá (Thông điệp), 3 lá (Quá khứ • Hiện tại • Tương lai),
  10 lá (Celtic Cross).
- Trải bài ngẫu nhiên thật: xáo trộn Fisher-Yates, mỗi lá có 50% xuất hiện
  ở trạng thái ngược với giải nghĩa riêng.
- Hiệu ứng lật bài 3D, mặt sau bài vẽ bằng CSS, ảnh lá ngược tự xoay 180°.

## Cách chạy

Mở file `index.html` trực tiếp, hoặc bật GitHub Pages:
Settings → Pages → Deploy from a branch → Branch: `main`, thư mục `/ (root)` → Save.
Trang sẽ chạy tại `https://diepvu203.github.io/Test/`.

## Lưu ý

Nội dung giải nghĩa chỉ mang tính tham khảo và giải trí, không thay thế cho
lời khuyên chuyên môn về sức khỏe, pháp lý hay tài chính.
