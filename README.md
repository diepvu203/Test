# Ví Da Nam Midori

Trang giới thiệu và bán ví da nam Midori — một file `index.html` duy nhất,
ảnh sản phẩm nhúng trực tiếp trong trang nên mở là chạy, không cần kèm file ảnh.

## Cách chạy

Mở file `index.html` trực tiếp, hoặc bật GitHub Pages:
Settings → Pages → Deploy from a branch → Branch: `main`, thư mục `/ (root)` → Save.
Trang sẽ chạy tại `https://diepvu203.github.io/Test/`.

## Cần cập nhật

- Giá bán: sửa dòng "Giá bán: đang cập nhật" trong `index.html`.
- Nút "ĐẶT HÀNG NGAY": gắn link bán hàng thật của shop (Facebook, Zalo,
  TikTok Shop, Shopee...) vào thuộc tính `href` của nút.
